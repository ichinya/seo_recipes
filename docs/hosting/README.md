# Хостинг

Раздел собран как единая база по хостингам. Текущее состояние провайдеров, накопительная история изменений и журнал аварий разделены, чтобы карточки компаний не превращались в ленту новостей.

## Разделы

| Раздел | Что внутри | Ссылка |
| --- | --- | --- |
| Провайдеры | Текущее состояние компаний: продукты, личный опыт, плюсы, минусы, ограничения и итоговая оценка | [Провайдеры](./providers/) |
| Изменения | Хронология цен, тарифов, локаций, запусков услуг, API, SLA и юридических условий по годам | [Изменения провайдеров](./changes/) |
| Инциденты | Хронология сбоев по годам и провайдерам, а также отдельные разборы массовых событий | [Инциденты](./incidents/) |
| Информационные материалы | Общие заметки по рынку, рискам, проверке отзывов и требованиям к размещению данных | [Информационные материалы](./info/) |
| Тестирование | Практические проверки VPS: сеть, диск, CPU, поддержка и базовая доступность | [Тестирование](./testing/) |
| Скрипты | Серверные инструкции, настройки Linux, Docker, swap, очистка диска и правила для ботов | [Скрипты](./scripts/) |
