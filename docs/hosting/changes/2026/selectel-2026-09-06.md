# Selectel: обновление событий сентября 2026

## universal.ru-7b: завершение деградации сетевых дисков

Событие с деградацией производительности сетевых дисков `universal.ru-7b`, начавшееся 31 августа 2026 года, было закрыто.

При оценке важно разделять:

- полную недоступность виртуальных машин;
- рост latency дисков;
- ошибки приложений из-за ожидания I/O;
- влияние на базы данных, очереди и backup.

Даже без полного outage длительная деградация storage может нарушать SLA приложений.

## Отдельная проблема создания VDS

После закрытия storage-инцидента в том же пуле была зафиксирована отдельная проблема создания новых VDS.

Совпадение по времени не означает общую причину: без опубликованного RCA события нужно анализировать отдельно.

## Вывод для пользователей

Для production на облачных дисках полезно иметь:

- мониторинг latency, а не только ping;
- метрики базы данных;
- внешний backup;
- restore-test;
- возможность переноса нагрузки между зонами.

Категория Selectel требует наблюдения, но изменения оценки должны основываться на повторяемости событий и опубликованных причинах.
