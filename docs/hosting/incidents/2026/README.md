# Инциденты хостингов в 2026 году

Последняя выборочная проверка IONOS TXL/S3/поддержки и Selectel KVM/MKS/VMware: **10 сентября 2026 года**. Предыдущие дополнения — 7–8 сентября. Последняя полная перепроверка всего watchlist: **31 августа 2026 года**.

Инциденты разделены по провайдерам. Массовые события, которые нельзя корректно отнести к одной компании, вынесены в отдельные разборы.

Отсутствие записи не означает отсутствие сбоев: у части провайдеров нет публичной status-панели или доступного архива. Время жизни status-записи также не всегда равно непрерывному простою каждого клиента.

## Дополнение 8 сентября — создание MKS Selectel `ru-3`

Добавлен инцидент создания Managed Kubernetes в `ru-3a`, `ru-3b`, `ru-3c`, опубликованный 7 сентября в 13:28 МСК. При повторной проверке **10 сентября** он остаётся в текущих сообщениях Selectel как `Issue`. Это provisioning: штатная работа существующих кластеров указана отдельно; сбой их масштабирования или остановка приложений не подтверждены.

Повторение класса проблем после 26 августа важно для аварийного развёртывания и CI/CD, но общая причина этих событий не установлена. Категория **«Рекомендую»** не меняется; повторяемость и итоговая длительность будут учитываться при следующей оценке. Детали и безопасные проверки — в [журнале Selectel](./selectel.md).

Это точечное дополнение по одному подтверждённому событию, а не новая полная перепроверка всех провайдеров.

Категория **«Рискованные»** сохраняется из-за уже описанных в карточке рисков аккаунта, оплаты и санкционной политики. Восстановление отдельных услуг их не отменяет.

На **28 сентября, 14:00–16:00 UTC**, запланировано отключение PostgreSQL API v1. Это не авария: клиентам нужно заранее проверить региональный API v2 и TOKEN auth для management automation.

## Как читать журнал

Большое число записей не обязательно означает низкое качество провайдера. Крупная компания с открытой status-панелью может публиковать больше событий, чем небольшой провайдер без публичной истории.

Для практической оценки важны:

- продолжительность;
- повторяемость;
- data plane или control plane;
- число затронутых регионов;
- прозрачность;
- компенсация;
- внешние резервные копии;
- успешный restore-test.
