## Правило разделения

У массового события должна быть одна каноническая страница с общей причиной и хронологией. В журналах затронутых провайдеров остаются краткая запись и ссылка на разбор. Это снижает дублирование и не создает ложного впечатления, что общая инфраструктурная авария произошла внутри каждого провайдера независимо.

Совпадение событий по времени не доказывает общую первопричину. Объединять записи можно только после официального технического разбора или нескольких независимых подтверждений.
