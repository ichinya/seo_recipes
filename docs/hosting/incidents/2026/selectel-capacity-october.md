Ни одно значение не используется как измеренный простой каждого тома. После закрытия отдельно проверьте своё приложение, ошибки ввода-вывода, БД и доступность пригодной копии, без нагрузочного бенчмарка или удаления томов ради проверки.

## Практические действия и категория

**Категория Selectel «Рекомендую» в каталоге пока не меняется; для Cloud Platform усилено предупреждение и по доступности работающих ресурсов, и по срочному восстановлению.** Личный тест отдельного московского VDS не подтверждает надёжность Cloud Platform в `ru-6/7/8`. №404813 показывает, что ограничивать оценку только provisioning уже нельзя; закрытие этого эпизода не отменяет необходимости проверить повторяемость и последствия для выбранного продукта.

Перед покупкой или аварийным переносом согласуйте минимальную конфигурацию, квоты, свободные ресурсы, диски, доступность поддержки и альтернативный путь восстановления. Нельзя считать успешный вход в кабинет проверкой provisioning. Работу уже созданных приложений проверяйте отдельно от API управления.

Если надёжность нужна прежде всего для срочного восстановления, эти открытые ограничения уже являются основанием **не полагаться на неподтверждённый запуск в затронутом пуле**. Дальнейший пересмотр категории должен опираться на длительность и повторяемость влияния, проверку нужной услуги, технические разборы и результаты восстановления — не на простое число карточек.

Перенос S3 без встроенного сервиса возможен только при доступности исходных данных, пригодной цели и проверке приложения. Порядок, различие `copy`/`sync` и приёмка данных — в [отдельном рецепте Rclone](../../testing/s3-migration-verification.md).
