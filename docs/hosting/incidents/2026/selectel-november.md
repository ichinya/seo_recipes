## Дополнение 11 ноября — создание VDS недоступно

**Проверено 11 ноября 2026 года, Asia/Yekaterinburg (UTC+5).** [Инцидент №410644](https://selectel.live/incidents/410644) опубликован **10 ноября, 18:31 МСК / 20:31 UTC+5**. На чтение карточка имеет `Issue`, без финального сообщения. Точная минута начала воздействия отдельно не установлена.

Провайдер сообщает о недоступном создании виртуальных машин через панель и API в Москве и Санкт-Петербурге. Заявлено обнаружение причины, но технический разбор не опубликован. Это отказ операции создания, **не подтверждённая остановка уже работающих VDS**. Связь с октябрьским ограничением создания VM и другими ноябрьскими инцидентами не установлена.

Практический риск — невозможность быстро развернуть замену или резервную среду. Проверять доступность приложения и возможность создания новой VM следует раздельно. Не удалять рабочую VM ради испытания; платное создание тестового ресурса требует отдельного решения.

Повторно прочитанная [карточка бэкапов №410193](https://selectel.live/incidents/410193) также остаётся `Issue`. Это обновление проверки прежнего события, не новая авария 11 ноября. Потеря старых копий или отказ всех операций восстановления не заявлены. Категории этим дополнением не меняются.

## Оценка и проверка

Категория **«Рекомендую» для ранее протестированного VDS сохраняется**, но не является гарантией всех продуктов Cloud Platform. Повторяемость сетевых проблем и ограничения backup требуют отдельной оценки нужного продукта и сценария восстановления.

План диагностики: сравнить HTTP/TLS приложения из независимых сетей, состояние VM и управления; для backup проверить содержимое и результат восстановления. Передавать поддержке время с часовым поясом, регион и идентификатор ресурса, без секретов. Клиентские тесты, расчёт SLA и проверка целостности данных здесь не выполнялись.
