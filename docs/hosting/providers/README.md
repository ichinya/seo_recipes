# Провайдеры

Здесь собраны отдельные страницы по хостингам, облакам и VPS/VDS-провайдерам. Действующие провайдеры разделены на четыре практические группы: что можно рекомендовать, что выглядит нормальным с оговорками, кандидаты на тест и рискованные или спорные варианты. Каталоги и прекратившие работу сервисы вынесены отдельно и не участвуют в рейтинге действующих провайдеров.

Крупные изменения тарифов, инфраструктуры и условий вынесены в отдельные страницы рядом с основной карточкой соответствующего провайдера.

Иконки в списке провайдеров:

- `fa-circle-check` - хороший / рабочий вариант;
- `fa-server` - кандидат на тест;
- `fa-triangle-exclamation` - сомнительный или рискованный вариант.
