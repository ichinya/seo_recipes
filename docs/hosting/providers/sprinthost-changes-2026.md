# Sprinthost и Sprintbox в 2026 году: новые цены, S3 и резервные копии

- [Основная карточка Sprinthost](./sprinthost.md)
- [Обзор Sprintbox](./sprintbox.md)

В 2026 году в экосистеме Sprinthost изменились цены на хостинг, домены и дополнительные услуги, а также появилось собственное S3-хранилище для клиентов Sprinthost и Sprintbox.

## Виртуальный хостинг с 1 января

16 декабря 2025 года провайдер заранее опубликовал новые цены, которые начали действовать **1 января 2026 года**.

Изменение затронуло основные линейки виртуального хостинга, Bitrix-тарифы и часть специальных планов. Перед сравнением с другими хостингами нужно смотреть одновременно:

- помесячную цену;
- цену при оплате за год;
- число сайтов и баз данных;
- лимиты нагрузки;
- объём диска;
- стоимость дополнительных ресурсов;
- условия продления после акции.

Старую цену из обзора нельзя использовать без даты проверки.

## Домены и дополнительные услуги с 1 февраля

16 января Sprinthost сообщил об изменении стоимости регистрации и продления доменов с **1 февраля 2026 года**.

Для `.RU` и `.РФ` цена зависит от регистратора. В опубликованной таблице для доменов у Спринтнеймс указаны:

| Операция | Цена с 1 февраля 2026 года |
| --- | ---: |
| Регистрация `.RU` / `.РФ` | 179 ₽ |
| Продление `.RU` / `.РФ` | 339 ₽ |

У доменов, находящихся у других регистраторов, условия отличаются. Перед массовым продлением нужно проверить фактического регистратора каждого домена в панели.

## Резервные копии Sprintbox

С 1 февраля изменилась стоимость дополнительного backup для боксов:

| Объём диска бокса | Дополнительный backup |
| --- | ---: |
| 7–20 ГБ | 75 ₽ |
| 21–40 ГБ | 150 ₽ |
| 41–70 ГБ | 260 ₽ |
| 71–100 ГБ | 375 ₽ |
| 101–129 ГБ | 480 ₽ |
| 130–300 ГБ | 890 ₽ |

Перед заказом нужно уточнить:

- периодичность создания копии;
- число точек восстановления;
- где физически хранится backup;
- сохраняется ли копия при блокировке или удалении бокса;
- можно ли скачать backup наружу;
- сколько занимает восстановление;
- является ли дополнительный backup независимым от основного хранилища.

## S3-хранилище с 13 апреля

13 апреля Sprinthost запустил S3-хранилище в режиме beta. Сервис доступен клиентам Sprinthost и Sprintbox через панель управления.

Провайдер заявляет:

- S3 API;
- хранение файлов и архивов в bucket;
- репликацию;
- масштабирование объёма;
- первый bucket за 1 ₽ на старте beta.

Символическая цена первого bucket не описывает полную стоимость эксплуатации. Нужно отдельно проверить:

- стоимость гигабайта хранения;
- исходящий трафик;
- операции `PUT`, `GET`, `LIST`, `DELETE`;
- minimum storage duration;
- versioning и lifecycle;
- CORS;
- presigned URLs;
- лимиты объектов и запросов;
- SLA;
- географию и независимость от площадки Sprintbox.

## S3 как backup для Sprintbox

S3 может быть вторым уровнем хранения, но backup нельзя считать независимым только потому, что он использует другой протокол.

Нужно выяснить:

```text
Sprintbox VM
    ↓
S3 Sprinthost
    ↓
тот же или независимый failure domain?
```

Для критичных данных безопаснее иметь ещё одну копию у другого провайдера или локально.

Пример минимального теста:

```bash
aws --endpoint-url "$S3_ENDPOINT" s3 cp test.bin "s3://$BUCKET/test.bin"
aws --endpoint-url "$S3_ENDPOINT" s3 cp "s3://$BUCKET/test.bin" restored.bin
sha256sum test.bin restored.bin
```

Также нужен реальный restore-test приложения, а не только загрузка одного файла.

## Платные SSL-сертификаты

С 15 марта 2026 года годовая услуга GlobalSign у Sprinthost фактически состоит из двух сертификатов сроком по 199 дней. Второй сертификат нужно выпустить до окончания первого.

Это важно для проектов, где сертификат устанавливается вручную на VPS или внешнем сервере: оплаченный год не означает, что один файл сертификата будет действовать весь год без перевыпуска.

## Влияние на категории

- **Sprinthost** остаётся в категории «Рекомендую».
- **Sprintbox** остаётся в категории «Норм».

Запуск S3 расширяет набор услуг, но не заменяет практический тест диска, сети, backup и восстановления. Изменения цен нужно учитывать в полной стоимости, а не рассматривать как показатель надёжности.

## Checklist

- [ ] Перепроверена цена текущего тарифа и продления.
- [ ] Установлен фактический регистратор доменов.
- [ ] Учтена новая стоимость дополнительного backup Sprintbox.
- [ ] Проверены периодичность и retention копий.
- [ ] S3 протестирован через API, а не только через панель.
- [ ] Проверены операции, трафик, CORS и presigned URLs.
- [ ] Есть независимая копия за пределами экосистемы Sprinthost.
- [ ] Для GlobalSign настроено напоминание о втором выпуске.
