# Контроль платных подписок Cloudflare для AI-агентов

Проверено 27 ноября 2026 года по [анонсу от 25 ноября](https://developers.cloudflare.com/changelog/post/2026-11-25-activate-pay-as-you-go-cli-mcp/). CLI cf и MCP позволяют активировать Workers Paid, R2 и Zero Trust. Для CLI требуется cf 1.0.0-rc.5 или новее, повторная OAuth-авторизация, подтверждённый email и настроенный способ оплаты. Поддерживающие спецификацию MCP 2026-07-28 и elicitation клиенты запрашивают согласие с ценой; остальные направляют пользователя в Dashboard. Наличие такого диалога не заменяет политику бюджета.

| Продукт | Условия в анонсе |
| --- | --- |
| Workers Paid | $5 в месяц плюс потребление; включено 10 млн запросов и 30 млн CPU-мс |
| R2 | 10 GB бесплатного месячного хранения; сверх квот и другие операции тарифицируются по правилам продукта |
| Zero Trust | До 50 пользователей на Free; платные возможности отдельно |

Цены проверять перед активацией, не считать бесплатную квоту жёстким лимитом расходов.

## Подготовка и политика доступа

Используйте отдельный тестовый аккаунт, с согласованным бюджетом, без production-токенов. Зафиксируйте account ID, продукт, текущую подписку, квоты, прогноз базовой и переменной платы, налоги, срок согласия и владельца решения. Инструменты чтения отделите от инструментов изменения подписок. Не выдавайте агенту billing/write-разрешения для обычного SEO-аудита. При OAuth-переавторизации изучите фактически запрошенные scopes; если минимальные права недоступны, оставьте активацию человеку в Dashboard.

Проверка CLI без финансовых действий:

```bash
command -v cf
cf --version
cf --help
cf auth --help
```

Только оператор после проверки scopes выполняет `cf auth login`; сама авторизация не является согласием на подписку. Точные команды активации зависят от версии: используйте встроенную справку и подтверждённую документацию, не подбирайте команды экспериментально в рабочем аккаунте.

## Проверяемый контракт согласования

В оркестраторе храните одноразовое решение, привязанное к account ID, SKU/плану, валюте, максимальной согласованной оценке, сроку и уникальному operation ID. Любое изменение плана или оценки требует нового согласия. Если неизвестны текущая подписка, стоимость, полномочия или состояние операции, остановите изменение и запросите сверку человеком. Согласие на одно действие не распространяется на последующие расходы.

| Тест на заглушке billing API | Ожидаемое поведение |
| --- | --- |
| Только чтение | Нет вызова активации |
| Отказ пользователя / отсутствует согласие | Нет вызова активации |
| Цена выросла после согласования | Новое согласие |
| Другой account ID | Запрет |
| Истёк срок согласия | Запрет |
| Timeout после отправки | Состояние unknown; сверка без автоматического повтора |
| Подписка уже активна | Не активировать повторно |

Журналировать ID операции, время UTC, продукт, согласованную оценку, решение и итог сверки; не журналировать OAuth-токены, данные карты или секреты. Бюджет контролировать в своём шлюзе, с независимыми уведомлениями по usage. Уведомления Cloudflare не считать гарантированным автоматическим отключением затрат.

## Реальный пример сбоя

[Cloudflare Billing Issues](https://www.cloudflarestatus.com/incidents/qlwszxx4667e): 26 ноября 09:28–09:37 UTC (14:28–14:37 UTC+5) объявлены проблемы изменения подписки R2; инцидент закрыт. Это не доказательство двойного списания или недоступности R2-объектов.

При timeout, 5xx или неоднозначном ответе: остановить повторы, прочитать текущую подписку в Dashboard или документированном read-only API, сверить расходы и историю операции. Если статус всё ещё неизвестен, обратиться в поддержку. Не предполагать поддержку idempotency key там, где она не документирована.

Для оценки затрат AI Search см. [Search for Agents](../../info/ai/cloudflare-search-for-agents.md). Его тарификация не тождественна активации Workers Paid.

## Приёмка и откат

Перед реальным пилотом выполнить матрицу тестов с заглушкой и проверить отсутствие финансовых запросов в логах. Реальную активацию разрешать только после отдельного согласования конкретной подписки. После пилота проверить список активных продуктов и usage; отмена подписки может затронуть ресурсы и не гарантирует возврат средств. Не удалять их автоматически. Живые финансовые действия и тесты при подготовке не выполнялись.
