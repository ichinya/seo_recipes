# Ноябрь 2026 — проверка релизов для сайтов и CI

**Источники проверены 9 ноября 2026 года, UTC+5.** Ниже — датированные обновления 3–6 ноября, не отчёт о выполненных тестах. Действующие настройки репозиториев, серверов и аккаунтов не менялись.

## WordPress 7.2 Beta 4 — 3 ноября

[Официальный релиз](https://wordpress.org/news/2026/11/wordpress-7-2-beta-4/) предназначен для тестовой среды, не для рабочих или критичных сайтов. В анонсе финал 7.2 запланирован на 8 декабря; это план из конкретной публикации, не подтверждённый выпуск. Календарь перед миграцией нужно проверить повторно.

Существующий [developer preview](../../cookbook/wordpress/wordpress-7-2-developer-preview.md) содержит более ранний контекст; эта запись не переаттестовывает его старые сроки. Для staging проверить тему и плагины, редактор блоков, REST API, Abilities API, ревизии и обновления переводов. Сохранить версии компонентов, результат каждого сценария и возможность возврата к исходной копии. Beta не заменяет установку стабильных security-обновлений production.

## PHP 8.6.0 RC5 — 5 ноября

[Архив PHP за 2026 год](https://www.php.net/archive/2026.php/) объявляет RC5 тестовым релизом; первый стабильный 8.6.0 запланирован на 19 ноября. Не переключать рабочий FPM на RC и не считать будущую дату гарантией выпуска.

В изолированной среде сравнить действующую версию PHP и RC: установку зависимостей, расширения, тесты приложения, deprecated-сообщения и HTTP-поведение через FPM. Проверка `composer check-platform-reqs` не заменяет интеграционные тесты и не подтверждает совместимость каждого плагина WordPress.

## Dependabot APM — 3 ноября

[GitHub объявил version updates для Agent Package Manager](https://github.blog/changelog/2026-11-03-dependabot-version-updates-support-agent-package-manager/): поддерживаемые Git-зависимости из `apm.yml`, обновление `apm.lock.yaml` при наличии. Это **не security updates** для APM. Внедрение относится только к проектам, действительно использующим такой манифест.

На отдельном тестовом репозитории проверить diff обновления, lockfile и совместимость инструкций агента. Изменённый skill или prompt — недоверенное содержимое до ревью, а не основание автоматически расширять доступы агента. Auto-merge не включать как побочный эффект знакомства с функцией.

## CodeQL 2.27.3 и 2.27.4 — 3–4 ноября

[2.27.3](https://github.blog/changelog/2026-11-03-codeql-2-27-3-adds-python-3-15-features-and-json-data-extensions/) добавляет JSON data extensions и опциональную модель угроз `ai` для LLM-generated data. Встроенных source-моделей у неё нет: требуется собственное описание источников. Изменения CFG GitHub Actions могут потребовать адаптации custom queries.

[2.27.4](https://github.blog/changelog/2026-11-04-codeql-2-27-4-improves-accuracy-and-query-metadata/) улучшает точность ряда запросов и проверку symlink при упаковке/публикации CodeQL packs. Для сравнения использовать один commit и query suite, сохранить версии, SARIF и разницу находок. Меньше alerts не означает отсутствие уязвимостей. Пример для поддерживаемой части приложения, например JavaScript/TypeScript, не выдавать за анализ всего PHP-бэкенда.

## Copilot Code Review API — 6 ноября

[Анонс GitHub](https://github.blog/changelog/2026-11-06-copilot-code-review-api-management-and-review-overview-updates/) добавляет управление настройками через REST/GraphQL и атрибуцию AI-ревью: уровень проверки и заявленные источники комментария — skills, MCP, instructions.

Первый этап — read-only inventory доступных настроек и разрешений на уровне repository/organization/enterprise. Не обещать одинаковую поддержку токенов на всех уровнях. Автоматическое ревью, изменение политики, подключение MCP и расходы требуют отдельного решения. Заявленный источник комментария не доказывает истинность самого замечания.

## Результат проверки

Заполнить для каждого теста: версия, среда, источник и дата, ожидаемый результат, фактический результат, ограничения и решение внедрить/отложить. Сейчас фактические результаты не получены. [Памятка о cloud secrets](./github-secret-scanning-cloud-credentials-2026.md) дополняет этот список, но не гарантирует обнаружение секретов во всех источниках.
